# 💻 Prácticas de Desarrollo Web con Flask

Repositorio académico de prácticas para el aprendizaje de desarrollo de aplicaciones web utilizando:

- Python
- Flask
- HTML
- CSS
- JavaScript
- Formularios web
- Git y GitHub

---

## 🎯 Objetivo

Desarrollar de manera progresiva aplicaciones web utilizando Python y Flask, comprendiendo la relación entre:

**Python → Flask → HTML → CSS → JavaScript**

Las prácticas están organizadas para avanzar desde la creación de una aplicación web básica hasta aplicaciones con formularios, almacenamiento de información y bases de datos.
